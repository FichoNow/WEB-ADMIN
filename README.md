# web-admin

Panel de administración desarrollado en Next.js + TypeScript.

## Requisitos

- npm >= 10
- Node >= 20
- La API (`API-BD`) corriendo y accesible

## Instalación

Instalar dependencias:

`npm install`

## Variables de entorno

Crear un archivo `.env.local` con:

```
API_URL=http://localhost:3000
```

## Scripts

### Desarrollo

`npm run dev`

Ejecuta el servidor en modo desarrollo.

### Build

`npm run build`

Compila el proyecto.

### Producción

`npm run start`

Ejecuta la versión compilada.
